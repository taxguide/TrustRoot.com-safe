#. Keep your product key available during the installation process.

----------------------------------------------------

#. Download the latest **Webroot SecureAnywhere** installer.
#. Run the downloaded setup file on your Windows or Mac computer.
#. Follow the on-screen installation instructions.
#. Complete the installation and launch Webroot.
#. Enter your product key again if prompted.
#. Allow Webroot to update to the latest version.
